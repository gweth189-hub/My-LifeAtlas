# LifeAtlas 🌍

LifeAtlas is a travel scrapbook made with HTML and CSS. It contains pictures and links to information for ten places around the globe that I hope to visit someday.

This is one of my early advanced projects for stardance. I built it while still learning web development, and I wanted to create something connected to my interests in history, culture and nature.

## Why I Built It

I chose these destinations because each one has something interesting about it. Some are known for their history, others for their landscapes and culture. I also wanted people viewing the website to discover places they might want to visit too.

## features on LifeAtlas
1. Ten destinations from different parts of the world with their pictures(for each destination)
2. Short descriptions.
3.Links to find more information.
4.Custom styling using CSS.
5.A simple layout for viewing the destinations.

## Destinations(the 10 places I would love to visit)
