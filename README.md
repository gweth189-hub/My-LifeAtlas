# 🌍 LifeAtlas — Explore the World

**Ten destinations. Endless possibilities. One dream.**

LifeAtlas is a travel destination scrapbook built with HTML and CSS. It showcases ten destinations around the world that i would love to visit (and may be someone's else dream too), highlighting their unique places, landscapes, and cultural attractions.

## ✨ Features

- 🌎 **10 destinations** across different parts of the world.
- 🖼️ Images to bring each destination to life.
- 📝 Short descriptions introducing each place.
- 🔗 Information links for further exploration.
- 🎨 Custom CSS styling, including image borders, spacing, and destination layouts.
- 📱 Responsive image sizing for different screen widths.
- 🔗 Footer links to my GitHub and Instagram profiles.

## 🛠️ Technologies Used

- **HTML5** — page structure and content.
- **CSS3** — colors, typography, spacing, images, and layout.
- **GitHub Pages** — website hosting.

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools  required.
